# 🤖 MyBot (Android App)
![Android](https://img.shields.io/badge/Platform-Android-green?logo=android)
![Java](https://img.shields.io/badge/Language-Java-blue?logo=java)
![Status](https://img.shields.io/badge/Status-Active-brightgreen)

A simple Android Studio project that acts as a basic bot to interact with users and perform simple tasks.

## 🚀 Features

- 📱 Simple Android UI  
- 💬 Basic bot interaction  
- ⚡ Lightweight and fast  
- 🎯 Easy to use  
- 🧠 Beginner-friendly project

## 🛠️ Tech Stack

- Language:Java  
- IDE: Android Studio  
- UI: XML Layouts  
- Platform: Android

## 🎯 Purpose

This project was built to improve my Android development skills and understand how UI interaction and logic handling work in real applications.
